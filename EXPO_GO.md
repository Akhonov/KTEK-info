# Запуск КТЭК на телефоне через Expo Go

Мобильная версия находится в папке `mobile`. Она открывает полный интерфейс ветки `aibar` внутри нативной оболочки Expo Go, поэтому сохраняются карта, Firebase-авторизация, объекты, телеметрия и редактор сети.

## Первый запуск

1. Установите **Expo Go** на Android или iPhone.
2. Подключите телефон и компьютер к одной Wi-Fi сети.
3. В PowerShell из корня проекта выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start-expo.ps1
   ```

4. Разрешите Python и Node.js доступ к частной сети, если Windows покажет запрос брандмауэра.
5. Отсканируйте появившийся QR-код приложением Expo Go.

Скрипт автоматически:

- определяет IP компьютера;
- запускает веб-ядро КТЭК на порту `8000` с доступом из локальной сети;
- передаёт правильный адрес в мобильное приложение;
- запускает Expo Go в LAN-режиме на порту `8081`.

## Если карта не подключилась

- Проверьте, что телефон не использует мобильный интернет или гостевую Wi-Fi сеть.
- Введите адрес, показанный скриптом, на экране подключения приложения.
- Проверьте с телефона в браузере адрес вида `http://192.168.1.10:8000/index.html`.
- Короткое нажатие на кнопку `↻` перезагружает карту; долгое нажатие возвращает к настройке адреса.

## Ручной запуск

В одном окне PowerShell запустите веб-карту:

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

Во втором окне:

```powershell
cd mobile
$env:EXPO_PUBLIC_KTEK_WEB_URL="http://IP_КОМПЬЮТЕРА:8000/index.html"
npm run start:lan
```

Для карты и Firebase требуется интернет. Компьютер должен оставаться включённым, пока используется версия Expo Go.

## Проверка из другого дома или другой сети

Для удалённого тестирования запустите из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-expo-remote.ps1
```

Сценарий создаёт два временных защищённых туннеля: один для Expo Go, второй — для веб-интерфейса карты. После запуска:

1. Дождитесь нового QR-кода в открывшемся окне PowerShell.
2. Сделайте снимок QR-кода и отправьте его другу. Старый LAN QR-код для этого не подходит.
3. Друг устанавливает Expo Go и сканирует присланный QR-код с другого экрана.
4. Не закрывайте окно PowerShell и не выключайте компьютер до конца проверки.

Телефоны могут использовать разные Wi-Fi сети или мобильный интернет. При каждом новом запуске удалённого режима адрес и QR-код меняются. Публичный сервер отдаёт только файлы, необходимые приложению; остальные файлы проекта недоступны.
