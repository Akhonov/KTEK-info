# Smart City

Этот репозиторий содержит интерфейс цифровой модели тепловых сетей и GIS-карты для диспетчерского управления.

## Описание

Проект объединяет:
- карту тепловых сетей и объектов;
- цифровые паспорта домов и теплоузлов;
- мониторинг дефектов, аварий и аномалий;
- сценарный режим и логика управления сетью;
- панели для полевых инженеров и планшетного АРМ.

## Структура проекта

- `index.html` — основное окно приложения
- `app.js` — логика карты, слоёв и событий
- `data_loader.js` — загрузка и нормализация данных
- `styles.css` — стилевое оформление интерфейса
- `*.json` — исходные и резервные данные по сетям и объектам

## Запуск

1. Запустите локальный веб-сервер в папке проекта.
2. Откройте `index.html` в браузере.
3. Проверьте работу карты, слоёв и геокомпонентов.

## Expo Go

Для запуска полного интерфейса на Android или iPhone подготовлен Expo-проект в папке `mobile`. Инструкция для локальной сети и удалённого тестирования из другого дома находится в файле [`EXPO_GO.md`](EXPO_GO.md). Удалённый режим запускается командой `powershell -ExecutionPolicy Bypass -File .\start-expo-remote.ps1`.

## Важное замечание по геоданным

Для точных геоданных обязательна проверка по реальным источникам: актуальные координаты объектов, карта района и привязка узлов к инфраструктуре. Не следует использовать случайные или только визуально подобранные координаты без верификации.
